# CARINI_PROJECT

CARINI_PROJECT는 자동차에 대한 지식이 부족한 사용자들을 위해 **자동차 견적을 맞춰주는 웹 프로젝트**입니다.  
이 프로젝트는 **카카오 챗봇**을 활용하여 사용자들에게 간편한 자동차 견적 서비스를 제공합니다.

---

## 🛠 프로젝트 개요

- **프로젝트명**: CARINI_PROJECT
- **목적**: 자동차에 대한 경험이나 지식이 없는 사용자들을 위해 **자동차 견적 서비스** 제공
- **주요 기능**:
  - 카카오, 네이버, 구글 소셜 로그인
  - 회원가입 시 비밀번호 암호화 및 입력값 검증
  - 역할별 인증 및 인가 처리 (예: 관리자, 일반 사용자)
  - 특정 조건에 맞는 차량 필터링 기능
  - 현재 위치 기반 대리점 위치 표시
  - **AWS**를 이용한 배포
  - 아이디 및 비밀번호 찾기 시 **문자 인증** 구현

---

## 🌐 개발 환경

- **프로그래밍 언어**: Java (JDK 1.8), HTML/CSS, JavaScript, Python
- **서버**: Apache, Apache Tomcat, AWS EC2
- **프레임워크**: Spring Boot
- **데이터베이스**: MySQL, AWS RDS
- **IDE 및 도구**:
  - Spring Tool Suite
  - Postman
  - NAVICAT
- **API**:
  - 카카오, 네이버, 구글 로그인 API
  - 카카오 지도 API
  - CoolSMS 문자 API
  - 카카오 챗봇 API

---

## ⚙️ 시스템 아키텍처 및 데이터베이스 설계

### 시스템 아키텍처

# 주요 페이지 설명

---

## 1. 📋 메인 페이지 (Home Page)
- **URL**: `/`
- **설명**:
  - CARINI 프로젝트의 첫 화면으로 사용자에게 자동차 견적 서비스를 소개하는 페이지입니다.
  - 주요 기능:
    - 프로젝트 소개 및 주요 서비스 강조.
    - "로그인" 또는 "회원가입" 버튼 제공.
    - 로그인하지 않은 사용자를 대상으로 간단한 사용 가이드 제공.

---

## 2. 🔑 로그인 페이지 (Login Page)
- **URL**: `/auth/login`
- **설명**:
  - 소셜 로그인을 통해 사용자 인증을 처리하는 페이지입니다.
  - 주요 기능:
    - 카카오, 네이버, 구글 소셜 로그인 버튼 제공.
    - 기존 사용자 로그인 처리.
    - 비밀번호 찾기 및 회원가입 페이지로 이동 가능한 링크 제공.

---

## 3. 📝 회원가입 페이지 (Sign-Up Page)
- **URL**: `/auth/signup`
- **설명**:
  - 신규 사용자를 위한 회원가입 페이지입니다.
  - 주요 기능:
    - 이메일, 비밀번호, 이름 등의 정보 입력 및 검증.
    - 비밀번호 복잡성 검증 (예: 최소 길이, 특수 문자 포함).
    - 소셜 계정을 통한 간편 회원가입 지원.
    - 약관 동의 및 개인정보 처리 방침 확인.

---

## 4. 🚗 차량 검색 및 필터링 페이지 (Car Search Page)
- **URL**: `/cars/search`
- **설명**:
  - 사용자가 자신의 조건에 맞는 차량을 검색하고 필터링할 수 있는 페이지입니다.
  - 주요 기능:
    - **필터 조건**:
      - 가격대, 브랜드, 연료 유형, 연비 등.
    - 조건에 맞는 차량 목록 표시.
    - 차량 상세 정보로 이동 가능한 링크 제공.

---

## 5. 🗺️ 대리점 위치 검색 페이지 (Dealership Location Page)
- **URL**: `/dealerships/map`
- **설명**:
  - 사용자의 현재 위치를 기반으로 가장 가까운 대리점을 찾을 수 있는 지도 페이지입니다.
  - 주요 기능:
    - 카카오 지도 API 연동.
    - 현재 위치에서 일정 반경 내의 대리점 표시.
    - 대리점 세부 정보(주소, 전화번호)와 경로 제공.

---

## 6. 🛠️ 관리자 페이지 (Admin Dashboard)
- **URL**: `/admin/dashboard`
- **설명**:
  - 관리자 전용 페이지로, 시스템 운영과 관리 작업을 수행합니다.
  - 주요 기능:
    - 사용자 정보 관리 (추가, 삭제, 수정).
    - 차량 데이터 관리.
    - 대리점 데이터 추가 및 수정.
    - 사용자 통계 및 시스템 로그 확인.

---

## 7. ✨ 설문 페이지 (Survey Page)
- **URL**: `/surveys/[id]/survey`
- **설명**:
  - 자동차 견적과 관련된 사용자 설문조사를 진행하는 페이지입니다.
  - 주요 기능:
    - 질문 유형별 입력 지원:
      - 단일 선택, 다중 선택, 텍스트 입력.
    - 진행률 표시 바 제공.
    - 답변 저장 및 결과 제출.

---

## 8. ✅ 설문 완료 페이지 (Survey Complete Page)
- **URL**: `/surveys/[id]/complete`
- **설명**:
  - 설문조사를 완료한 사용자에게 감사 메시지와 결과 요약을 제공하는 페이지입니다.
  - 주요 기능:
    - 설문 완료 확인 메시지 표시.
    - 추가 서비스(예: 견적 요청)로 이동 가능한 링크 제공.

---

## 9. ⚙️ 설정 페이지 (Settings Page)
- **URL**: `/settings`
- **설명**:
  - 사용자 계정 및 개인화 설정을 관리하는 페이지입니다.
  - 주요 기능:
    - 비밀번호 변경.
    - 알림 설정 관리.
    - 개인정보 업데이트.

---

## 10. 🚧 오류 페이지 (Error Page)
- **URL**: `/error`
- **설명**:
  - 잘못된 URL에 접근하거나 서버 오류가 발생했을 때 표시되는 페이지입니다.
  - 주요 기능:
    - 사용자 친화적인 에러 메시지 제공.
    - 홈 페이지로 돌아가는 버튼 제공.
